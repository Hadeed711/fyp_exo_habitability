AI Exoplanet Habitability Explorer: AI-Powered Exoplanet Analysis System
Project Vision
To create an intelligent, interactive system that uses AI and data visualization to predict, analyze, and explore the habitability of exoplanets from NASA’s datasets — turning complex astrophysical data into an intuitive learning and discovery experience for both researchers and the public.

System Workflow
1. The system begins by acquiring and cleaning NASA’s exoplanet data.2. The AI/ML module processes the cleaned data and predicts habitability scores.3. The Backend API serves these predictions and raw data to the frontend.4. The Visualization module renders interactive charts and 3D orbit maps.5. The User Interaction module allows new planet input and displays instant predictions.6. The Explainability module provides transparency into AI decision-making.7. The system is deployed online for researchers and the public to explore.
